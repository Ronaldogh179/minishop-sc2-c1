# MiniShop — Carrito de Compras 🛒

Aplicación web desarrollada con Vanilla JavaScript para demostrar la manipulación del DOM, gestión de eventos y sincronización de datos en memoria sin frameworks.

## 🚀 Características
- Catálogo dinámico y gestión de carrito (agregar, incrementar, disminuir, eliminar).
- Cálculos en tiempo real y validación de reglas de negocio.
